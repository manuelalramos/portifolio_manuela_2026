# ✦ Sobre o projeto

Este é o meu **portfolio pessoal** — uma landing page que reúne tudo o que venho construindo entre **design, desenvolvimento web e experiências digitais**.

Mais do que uma vitrine, ele foi pensado como um espaço vivo para apresentar meus projetos, minha trajetória e minha forma de trabalhar. A estética mistura um lado **editorial, tecnológico e autoral**, refletindo tanto minha base de design quanto meu crescimento no front-end.

---

# ✦ O que tem no portfolio

- **Tela de entrada** com animação de abertura
- **Hero** com apresentação, stack e carrossel de ferramentas
- **Sobre mim** com download de currículo e atalho para certificados
- **Seção de projetos** com 7 trabalhos publicados, cada um com link para o site e para o GitHub
- **Processo de trabalho** (do briefing ao deploy)
- **Contato** com e-mail, WhatsApp, LinkedIn e GitHub
- **Página de certificados** dedicada

---

# ✦ Funcionalidades

- Cursor personalizado
- Menu mobile responsivo (com acessibilidade via `aria-*`)
- Scroll suave entre as seções
- Destaque automático do menu conforme a seção visível
- Animações de revelação ao rolar a página (IntersectionObserver)
- Layout totalmente responsivo (mobile, tablet e desktop)

# ✦ Como executar

```bash

git clone https://github.com/manuelalramos/PORTIFOLIO.git

# entrar na pasta
cd PORTIFOLIO
```

Depois é só abrir o `index.html` no navegador, ou usar a extensão **Live Server** no VS Code.
